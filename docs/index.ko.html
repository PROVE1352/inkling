Inkling 쓰기

사용 설명서

초대받아 쓰시는 분을 위한 설명서입니다. 메뉴가 어디 있는지 찾기 쉽게 정리했습니다.

MCP 연결과 에이전트 안내

Claude와 다른 MCP 클라이언트 연결, 도구 목록, 에이전트가 따를 순서를 적은 문서입니다.

다른 MCP 서버와 같이 쓰기

게임 엔진, 디자인 도구, 코드 저장소 같은 다른 MCP 서버와 같이 쓰는 예시입니다.

템플릿

페이지와 구조 템플릿, 변수, 입력 질문, 행 템플릿.

쿼리 블록

Dataview 문법 일부: TABLE, LIST, TASK, FROM, WHERE, SORT, LIMIT.

서버 운영

배포

리눅스 서버에 올리는 순서: HTTPS, 가입 키, 메일, 로그인 방식, 의미 검색, 업데이트.

운영

배포 점검표, 업그레이드, 상태 요약, 데이터베이스 튜닝.

백업과 복원

일정, 암호화, GFS 보관, 복원 테스트, rclone 외부 사본.

알려진 문제

아직 남은 문제를 영역과 심각도별로 정리했습니다.

연동

REST API

웹 앱, 스크립트, MCP 도구가 함께 쓰는 REST 계약.

웹훅

워크스페이스 이벤트를 내 주소로 받는 방법.

플러그인(실험 기능)

샌드박스 iframe 플러그인의 매니페스트, 런타임 API, 보안 모델.

볼트 동기화(실험 기능)

inklingctl로 옵시디언 볼트와 양방향 동기화.

프로젝트

구조

서버, 동시 편집, 웹 앱이 어떻게 맞물리는지.

로드맵

앞으로 할 일과 하지 않을 일.

성능 기록

성능을 손본 변경마다 전후 수치와 잰 방법을 적은 기록.
