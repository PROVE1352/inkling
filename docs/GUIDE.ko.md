# Inkling 사용 설명서

다른 분이 운영하는 Inkling 서버에 초대받아 쓰시는 분을 위한 문서입니다. 기능 설명보다는 "그 메뉴가 어디 있는지"를 찾기 쉽게 쓰려고 했습니다. 서버를 직접 설치하고 운영하시는 분은 [README.ko.md](../README.ko.md), [deploy/DEPLOY.md](../deploy/DEPLOY.md), [OPERATIONS.md](OPERATIONS.md)를 참고하시기 바랍니다. 영어판은 [GUIDE.md](GUIDE.md)입니다.

단축키는 맥(⌘) 기준으로 적었습니다. 윈도우나 리눅스에서는 ⌘ 대신 Ctrl을 누르시면 되고, 둘이 다른 경우는 아래 [단축키](#단축키) 표에 따로 적어 두었습니다. 메뉴 이름은 앱 언어를 한국어로 두었을 때 화면에 나오는 이름 그대로입니다.

## 시작하기

### 로그인

처음 가입하실 때는 서버 운영자에게 받은 가입 키가 있어야 합니다. 로그인 화면에서 '가입 키로 가입하기'를 누르고 키를 붙여 넣은 다음, 이름과 이메일, 비밀번호(8자 이상)를 입력하시면 됩니다.

비밀번호를 잊으셨다면 로그인 화면의 '비밀번호를 잊었나요?'를 누릅니다. 관리자나 메일로 받은 재설정 코드가 있으면 '코드가 있어요'에 입력하시면 되고, 없으면 '코드가 없어요'에서 요청을 보내시면 됩니다. 서버가 메일을 보낼 수 있으면 재설정 메일이 오고, 그렇지 않으면 관리자가 코드를 따로 전해 드리게 됩니다.

화면 언어는 처음에는 브라우저 언어를 따릅니다. 바꾸시려면 설정 › 모양 › 언어에서 고르시면 됩니다.

### 워크스페이스

워크스페이스는 팀이 함께 쓰는 공간입니다. 처음 로그인하면 '새 워크스페이스 만들기'와 '초대 코드로 참여' 중 하나를 고르게 됩니다. 초대 링크(`…/join/<코드>`)를 받으셨다면 로그인한 상태에서 링크를 열고 '참여'를 누르시면 됩니다.

사이드바 맨 위에 있는 워크스페이스 이름을 누르면 워크스페이스 메뉴가 열립니다. 여기서 다른 워크스페이스로 옮겨 가거나, 멤버 관리, 워크스페이스 설정, 새 워크스페이스, 코드로 참여, 가져오기와 내보내기를 할 수 있습니다.

페이지 트리는 공유와 개인 두 구역으로 나뉘어 있습니다. 공유 구역의 페이지는 워크스페이스 멤버 모두가 읽고 고칠 수 있고, 개인 구역(자물쇠 표시)의 페이지는 본인만 볼 수 있습니다. 개인 페이지는 웹에 공유하거나 편집 잠금을 걸 수 없습니다. 페이지를 다른 구역으로 옮기시려면 오른쪽 패널의 속성에서 '개인으로 전환' 또는 '공유로 전환'을 누르시면 됩니다.

역할은 소유자, 관리자, 멤버 세 가지가 있습니다. 워크스페이스 설정은 소유자가 바꾸고, 웹 공개와 편집 잠금은 소유자와 관리자가 맡습니다.

### 페이지 만들기

새 페이지는 사이드바 위쪽의 '새 페이지'나 ⌘N으로 만듭니다. 바로 옆의 작은 화살표(˅)를 누르면 새 문서, 새 폴더, 새 데이터베이스, 새 캔버스, 템플릿에서 시작 중에서 종류를 고를 수 있습니다. ⌘N으로 만든 페이지가 최상위에 생길지, 지금 페이지 안이나 옆에 생길지는 설정 › 파일 · 링크 › 새 페이지 위치에서 정하시면 됩니다.

트리에서 페이지 위에 마우스를 올리면 + 버튼(하위 페이지 추가)과 ⋯ 메뉴가 나옵니다. ⋯ 메뉴는 우클릭으로도 열리고, 하위 페이지나 하위 폴더, 하위 데이터베이스를 만들거나 이동…, 복제, 이름 바꾸기, 즐겨찾기에 추가, 템플릿으로 저장 같은 일을 여기서 합니다. 페이지 순서를 바꾸거나 다른 페이지 안으로 넣고 싶을 때는 트리에서 끌어다 놓으시면 됩니다.

사이드바의 '오늘'을 누르면 오늘 날짜의 데일리 노트가 열립니다. 어제나 내일 노트는 명령 팔레트(⌘P)에서 열 수 있습니다.

### 찾기

⌘K는 검색으로, 제목과 본문을 함께 찾습니다. 제목만 알고 빨리 넘어가고 싶을 때는 ⌘O(빠른 전환)가 편합니다. ⌘P는 명령 팔레트인데, 페이지 이동 말고도 새 페이지 만들기, 휴지통 열기, 테마 바꾸기, 워크스페이스 바꾸기 같은 명령을 여기서 실행할 수 있습니다. 자주 여는 페이지는 페이지 머리글의 별(☆)을 눌러 즐겨찾기에 넣어 두시면 트리 위쪽에 따로 모입니다.

## 글쓰기

### 슬래시 메뉴와 블록

문서에서 `/`를 치면 블록을 고르는 메뉴가 뜹니다. 제목, 목록, 체크리스트, 토글 목록, 인용, 표, 코드 블록, 이미지와 파일 같은 기본 블록이 있고, Inkling에서 따로 넣은 블록도 몇 가지 있습니다.

콜아웃은 눈에 띄게 강조하는 상자입니다. 블록 안의 아이콘을 누르면 노트, 팁, 경고, 위험, 정보 중에서 종류를 바꿀 수 있습니다. 임베드 / 링크 카드는 YouTube, Figma, Google Docs 같은 링크를 붙여 넣으면 페이지 안에 띄워 주는 블록이고, 임베드와 미리보기 카드, 일반 링크 중에서 보이는 방식을 고를 수 있습니다. 수식 블록과 인라인 수식, 쿼리는 아래에서 따로 설명하겠습니다.

이미지와 파일은 페이지에 끌어다 놓기만 해도 들어갑니다. 맨 위의 큰 글씨가 제목이고, F2를 누르면 제목으로 바로 갑니다.

### 수식

한 줄을 따로 차지하는 수식은 `/` › 수식 블록으로 넣습니다. 문장 안에 넣을 때는 `$x^2$`처럼 달러 기호로 감싸서 입력하시거나, 글자를 고른 상태에서 ⌘⇧E를 누르시면 됩니다. 수식을 누르면 LaTeX를 고칠 수 있는 창이 열리고, 고치는 동안 결과가 바로 보입니다. `$5 and $10`처럼 가격을 적은 경우는 수식으로 바뀌지 않도록 해 두었습니다.

### 링크, 멘션, 태그

`[[`를 치면 다른 페이지로 가는 링크를 걸 수 있습니다. 목록에서 페이지를 고르셔도 되고, 아직 없는 페이지라면 '＋ 새 페이지: "…"'를 눌러 그 자리에서 만들 수도 있습니다. `![[`로 시작하면 링크 대신 그 페이지의 내용을 그대로 끼워 넣습니다.

`@`로는 멤버나 페이지를 멘션합니다. 멤버를 멘션하면 그 사람에게 알림이 갑니다. `#태그`처럼 쓰면 태그가 붙고, 사이드바의 '태그'에서 태그별로 페이지를 모아 볼 수 있습니다. 내부 링크에 마우스를 올리면 그 페이지를 미리 보여 주는데, 이게 거슬리시면 설정 › 파일 · 링크 › 링크 미리보기에서 끄시면 됩니다.

### 오른쪽 패널

페이지 오른쪽 위의 패널 버튼을 누르면 오른쪽 패널이 열립니다. 속성, 개요, 코멘트, 백링크, 미연결 멘션, 나가는 링크, 태그, 별칭, 로컬 그래프, 버전 히스토리가 이 안에 있습니다. 미연결 멘션은 다른 문서에서 이 페이지 제목을 쓰긴 했는데 아직 링크로 걸리지 않은 곳을 찾아 주는 기능입니다. 속성을 바로 고치고 싶을 때는 ⌘;를 누르시면 됩니다.

### 필기 모드

페이지 머리글 ⋯ 메뉴의 '필기 모드'를 누르면 필기 모드가 켜지고, 문서 위에 펜이나 손가락으로 글씨를 쓰거나 형광펜을 칠할 수 있습니다. 태블릿에서 쓰기 좋은 편입니다. 끝내실 때는 Esc를 누르시면 됩니다.

## 데이터베이스

데이터베이스는 '새 데이터베이스'로 만듭니다. 행 하나하나가 페이지이기 때문에, '행 페이지 열기'를 누르면 그 행을 보통 문서처럼 열어서 내용을 쓸 수 있습니다.

뷰는 표, 보드, 캘린더, 갤러리, 타임라인이 있고 뷰 탭의 '새 뷰'로 추가합니다. 속성은 '새 속성 추가'로 만들며 종류는 텍스트, 숫자, 선택, 다중 선택, 날짜, 체크박스, 사람, URL, 관계형, 롤업이 있습니다. '정렬 · 필터'에서 뷰마다 정렬 순서와 필터, 표시할 필드를 따로 정할 수 있고, 보드는 선택 속성을 기준으로 묶입니다.

관계형 속성은 다른 데이터베이스의 행과 연결할 때 씁니다. '연결된 데이터베이스에도 표시 (양방향)'를 켜 두면 상대 데이터베이스 쪽에서도 연결이 보입니다. 롤업은 이렇게 연결된 행의 값을 모아 계산하는 속성으로, 개수, 합계, 평균, 최솟값과 최댓값, 가장 이른 날짜와 늦은 날짜, 체크 비율, 고유값 중에서 고를 수 있습니다.

Excel이나 Google Sheets에서 복사한 칸은 그대로 붙여 넣으셔도 되고, 'CSV / Excel 가져오기…'로 파일을 올리셔도 됩니다. 지금 보고 있는 뷰는 '현재 뷰를 CSV로 내보내기'나 '현재 뷰를 Excel로 내보내기'로 파일로 받을 수 있습니다. 'Google Sheets 동기화…'는 웹에 게시한 시트를 주기적으로 가져오는 기능인데, 아직 실험 기능이라 서버에서 켜 둔 경우에만 보입니다.

## 그래프, 캔버스, 쿼리 블록

그래프(⌘G)는 워크스페이스의 모든 페이지와 링크를 한 화면에 그려 줍니다. 그래프 설정에서 제목으로 찾거나, 고아 노드 표시, 태그 노드 표시, 최상위 폴더별 색을 켜고 끌 수 있고, 노드끼리 당기고 밀어내는 힘도 조절할 수 있습니다. 지금 보고 있는 페이지 주변만 보고 싶을 때는 오른쪽 패널의 로컬 그래프가 더 편합니다.

캔버스는 끝없이 넓은 보드에 텍스트 카드, 페이지 카드, 링크 카드를 늘어놓는 기능입니다. 이미지는 끌어다 놓으면 카드가 됩니다. 옵시디언의 `.canvas` 형식과 호환되도록 만들었기 때문에 옵시디언과 파일을 주고받을 수 있습니다. 이미 쓴 문서가 있다면 문서의 ⋯ 메뉴에서 '캔버스로 펼치기'를 눌러 캔버스로 바꿀 수도 있습니다. 다만 캔버스는 아직 웹에 공유할 수 없습니다.

쿼리 블록은 `/` › 쿼리로 넣고, `LIST FROM #project`나 `TABLE status FROM "Projects"`처럼 Dataview 문법으로 조건을 적으면 맞는 페이지를 표나 목록으로 보여 줍니다. 페이지가 바뀌면 결과도 따라 바뀝니다. 문법은 [QUERY.md](QUERY.md)(영어)에 정리해 두었습니다.

비슷한 구조의 페이지를 자주 만드신다면 템플릿을 쓰시는 편이 좋습니다. '템플릿에서 시작'으로 페이지 하나나 하위 페이지까지 갖춘 구조를 한 번에 만들 수 있고, 직접 만든 페이지는 ⋯ 메뉴의 '템플릿으로 저장'으로 템플릿이 됩니다. 자세한 내용은 [TEMPLATES.md](TEMPLATES.md)(영어)를 참고하시기 바랍니다.

## 할 일과 캘린더

문서 안의 체크리스트 항목에 날짜를 붙이면 할 일로 잡힙니다. `- [ ] 보고서 📅 2026-09-30`이나 `[due:: 2026-09-30]`처럼 쓰시면 됩니다.

사이드바의 '마감'에서는 날짜가 지난 일, 이번 주, 앞으로 30일 안의 할 일을 모아 보여 줍니다. 여기 있는 '할 일 추가…'에 적으면 "Tasks" 문서에 체크리스트 항목으로 들어갑니다. '캘린더'는 날짜가 있는 항목을 월이나 주 단위로 보여 주는 화면인데, 빈 날짜를 누르면 그 날짜로 할 일이나 페이지, 데일리 노트를 만들 수 있고 항목을 끌어서 다른 날로 옮길 수도 있습니다.

Google 캘린더나 Apple 캘린더, Outlook에서 함께 보고 싶으시면 설정 › 캘린더 구독 (iCal)에서 구독 링크를 만드시면 됩니다. 이 링크를 아는 사람은 누구나 그 항목을 읽을 수 있으니 다른 사람에게는 알려 주지 않으셔야 합니다.

## 함께 쓰기

### 동시 편집

한 문서나 캔버스를 여러 사람이 동시에 고칠 수 있습니다. 다른 사람의 커서가 화면에 보이고, 머리글에 지금 들어와 있는 사람과 연결 상태가 표시됩니다. 연결이 끊긴 동안 고친 내용은 다시 연결될 때 합쳐집니다.

### 코멘트

코멘트는 오른쪽 패널의 코멘트에서 답니다. '현재 블록에 코멘트'를 누르면 커서가 있는 블록에 스레드가 달리고, '새 스레드'를 누르면 페이지 전체에 대한 스레드가 생깁니다. 코멘트 안에서도 `@`로 멘션할 수 있고, '답글'로 대화를 이어 가다가 이야기가 끝나면 '해결'을 누르시면 됩니다.

### 알림

오른쪽 위의 종 버튼에는 모든 워크스페이스의 알림이 함께 모입니다. 누군가 페이지나 코멘트에서 나를 멘션했을 때, 내 스레드에 답글이 달렸을 때, 나를 페이지 담당자로 정하거나 데이터베이스의 사람 칸에 넣었을 때, 그리고 내가 팔로우하는 페이지가 바뀌었을 때 알림이 옵니다. AI 에이전트가 쓴 멘션은 배지나 메일 없이 조용히 들어오고 요약 메일에 묶여서 갑니다. 에이전트가 여러 번 멘션해도 시끄럽지 않게 하려고 이렇게 정했습니다.

### 페이지 팔로우

페이지 머리글 ⋯ 메뉴의 '페이지 알림'에서 그 페이지의 알림을 얼마나 받을지 정합니다. '이 페이지 팔로우'나 '페이지와 하위 페이지 팔로우'를 고르면 그 페이지에서 일어나는 일을 받아 보게 되고, 기본값은 '멘션만'입니다. 아예 받고 싶지 않으면 '알리지 않음'이나 '음소거'를 고르시면 되는데, 음소거는 멘션 알림까지 막고 나에게 온 승인 요청만 통과시킵니다. '상속'은 상위 페이지나 워크스페이스 설정을 그대로 따릅니다. 'AI가 여기를 편집하면 하루 요약 받기'를 켜 두면 그 페이지 아래에서 AI가 고친 내용을 하루에 한 번 모아서 받을 수 있습니다.

설정 › 알림에서는 지금 팔로우 중인 항목을 한꺼번에 보고, 메일을 어떻게 받을지 정합니다. '바로 메일 받기'를 켜면 멘션과 답글, 담당 지정이 생길 때마다 메일이 오고, '요약 메일'은 매일이나 매주 한 번 나머지를 모아서 보내 줍니다. 서버에 메일 설정이 되어 있지 않으면 이 부분은 꺼져 있고 알림은 앱 안에만 쌓입니다.

### 활동

사이드바의 '활동'은 사람과 AI가 최근에 바꾼 내용을 최신순으로 보여 주는 화면입니다. 사람이 한 것만, 또는 AI가 한 것만 보거나, 앱이나 멤버, 페이지, 변경 종류로 걸러 볼 수 있습니다. '변경 내용 보기'를 누르면 실제로 어떤 줄이 바뀌었는지 나옵니다.

### 멤버

멤버는 워크스페이스 메뉴의 '멤버 관리'에서 봅니다. 다른 워크스페이스에서 이미 함께하고 있는 사람은 이름이나 이메일로 찾아서 바로 추가할 수 있고, 처음 오는 사람에게는 초대 링크를 보내시면 됩니다. '초대 링크 복사'는 사이드바 맨 아래에도 있습니다.

## 웹에 공유

페이지를 로그인 없이 볼 수 있는 링크로 공개하는 기능입니다. 공개와 공유 중지는 워크스페이스 소유자와 관리자만 할 수 있습니다.

1. 페이지 머리글의 지구본 버튼이나 트리 ⋯ 메뉴의 '웹에 공유'를 누릅니다.
2. '웹에 공개'를 누른 다음 링크를 복사해서 전하시면 됩니다.
3. 공개를 멈추고 싶을 때는 같은 창에서 '공유 중지'를 누르면 링크가 바로 막힙니다.

링크를 받은 사람은 읽기만 할 수 있고 고칠 수는 없습니다. 폴더를 공유하면 그 안의 페이지가 모두 함께 공개되는데, 개인 페이지는 빠집니다. 개인 페이지와 캔버스는 공유할 수 없습니다. 지금 무엇이 공개되어 있는지는 사이드바의 '웹 공유'에서 한눈에 볼 수 있고, 워크스페이스 전체에서 웹 공개를 막고 싶으면 소유자가 워크스페이스 설정 › 공개 링크에서 끄시면 됩니다.

## 편집 잠금

공유 페이지는 멤버 누구나 고칠 수 있기 때문에, 중요한 문서는 정해진 사람만 고치도록 잠가 둘 수 있게 했습니다. 잠근 뒤에도 다른 사람은 읽고 코멘트를 남길 수 있습니다.

1. 페이지 머리글이나 트리의 ⋯ 메뉴에서 '편집 잠금…'을 누릅니다.
2. '이 페이지와 하위 페이지 잠그기'를 켭니다.
3. 사람 항목에서 '담당자와 지정한 편집자만'이나 '모두(에이전트만 제한)'를 고릅니다. 편집자는 '편집자 추가…'로 넣으시면 됩니다.
4. 에이전트(MCP AI) 항목에서 '사람과 같게', '코멘트만', '읽기만' 중 하나를 고릅니다.

에이전트 쪽 설정은 소유자와 관리자를 포함해 모든 멤버의 에이전트에 똑같이 걸립니다. 워크스페이스 소유자와 관리자는 잠긴 페이지도 항상 고칠 수 있고, 잠금 설정을 바꿀 수 있는 사람도 이들과 페이지 담당자뿐입니다. 개인 페이지에는 잠금을 걸 수 없습니다. 잠긴 페이지에는 '잠김' 표시가 붙고, 고칠 권한이 없는 사람에게는 본문뿐 아니라 데이터베이스 칸이나 캔버스 카드, 속성까지 모두 읽기 전용으로 보입니다.

같은 창에는 에이전트 지침도 있습니다. 어떤 페이지를 지침으로 지정해 두면, AI 에이전트가 그 내용을 이 워크스페이스에서 지켜야 할 규칙으로 읽어 갑니다. 항상 읽게 할지, 조건에 맞는 페이지를 다룰 때만 읽게 할지, 이름으로 부를 때만 읽게 할지 고를 수 있습니다. 지침 페이지는 아무나 고치면 안 되기 때문에 지정하는 순간 자동으로 잠깁니다.

## 내 AI 연결하기 (MCP)

Inkling에는 MCP 서버가 들어 있어서, Claude Code나 claude.ai 같은 AI 앱을 내 계정으로 연결하면 그 앱이 내 노트를 읽고 쓸 수 있습니다. 연결은 사람마다 따로 하고, AI는 연결한 사람이 볼 수 있는 페이지만 다룹니다.

### 연결하기

연결에 필요한 서버 주소는 설정 › 연결 › MCP 서버에서 '주소 복사'를 눌러 얻을 수 있습니다. `https://notes.example.com/mcp` 같은 모양입니다.

Claude Code를 쓰신다면 터미널에서 다음 명령을 실행합니다.

```bash
claude mcp add --transport http inkling https://notes.example.com/mcp
```

그다음 Claude Code 안에서 `/mcp`를 실행하고 `inkling`을 골라 인증을 시작하면, 브라우저에 Inkling 연결 확인 화면이 뜹니다. 로그인이 필요하면 로그인하신 뒤 권한을 고르고 '허용'을 누르시면 됩니다. Claude Code가 SSH로 접속한 다른 컴퓨터에서 돌고 있다면 앱으로 돌아가는 버튼이 그 컴퓨터까지 닿지 않습니다. 이럴 때는 확인 화면의 '명령 복사'를 눌러서, 5분 안에 그 컴퓨터의 터미널에 붙여 넣어 실행하시면 됩니다.

claude.ai에서는 설정 › 커넥터 › Add custom connector를 열고 URL 칸에 위 주소를 넣은 뒤 연결하시면 됩니다. OAuth Client ID와 Secret 칸은 비워 두셔도 됩니다. 새 창이 뜨면 로그인하고 '허용'을 누릅니다.

### 읽기 전용과 읽기와 쓰기

연결 확인 화면에서 권한을 고르게 되어 있습니다. '읽기와 쓰기'는 페이지를 읽고 찾는 것 말고도 만들고, 고치고, 코멘트를 달 수 있는 권한입니다. '읽기 전용'은 읽고 찾기만 하고 아무것도 바꾸지 못합니다. AI에게 노트를 맡기는 게 아직 불안하시면 읽기 전용으로 먼저 써 보시는 것도 방법입니다. 권한을 나중에 바꾸시려면 연결을 끊고 다시 연결하셔야 합니다.

### AI가 할 수 있는 일과 못 하는 일

연결된 AI는 내가 속한 워크스페이스의 공유 페이지와 내 개인 페이지를 볼 수 있습니다. 페이지를 찾아 읽고(필요하면 한 부분만 읽기도 합니다), 지난번 이후 바뀐 내용을 따라가고, 페이지를 만들거나 일부를 고치고, 데이터베이스에 행을 넣고, 코멘트와 답글을 답니다. 내가 시작한 스레드라면 해결 처리도 하고, 페이지를 휴지통으로 보낼 수도 있습니다.

반대로 다른 사람의 개인 페이지나 내가 속하지 않은 워크스페이스는 볼 수 없습니다. 영구 삭제 도구는 일부러 만들지 않아서, AI가 지운 페이지는 언제나 휴지통에 남습니다. 편집 잠금이나 멤버, 공개 링크, 관리자 설정도 바꾸지 못하고, 잠금이 허락하지 않는 페이지는 고치지 못합니다.

### 경유 표시

AI가 한 일은 '내 이름 (앱 이름 경유)' 형태로 기록됩니다. 예를 들어 "김철수 (Claude 경유)"처럼 버전 히스토리와 코멘트, 활동 화면에 남습니다. AI가 만든 페이지에는 'AI가 작성 (… 경유)'이, AI가 고친 페이지에는 마지막 AI 편집 시각이 표시되고, AI가 페이지 전체를 바꾸기 전에는 'AI 편집 전' 스냅샷이 자동으로 저장되기 때문에 언제든 되돌릴 수 있습니다.

### 연결 관리

연결한 앱 목록은 설정의 '연결 관리'나 ⌘P 팔레트의 'MCP 연결 관리'에서 볼 수 있습니다. '연결 해제'를 누르면 그 앱의 접근이 바로 끊깁니다. 워크스페이스 소유자와 관리자는 워크스페이스 설정 › 연결된 에이전트에서 멤버들이 연결한 에이전트를 보고, 그 워크스페이스에서만 막을 수도 있습니다.

AI 에이전트에게는 페이지 내용을 지시가 아닌 데이터로 표시해서 넘깁니다. AI를 속이려는 것처럼 보이는 문구가 있는 페이지에는 '프롬프트 인젝션 의심 텍스트' 표시가 붙는데, 경고만 할 뿐 막지는 않고 잘못 잡히는 경우도 있습니다.

더 자세한 내용은 [MCP.md](MCP.md)(영어)를 참고하시기 바랍니다.

## 노션에서 가져오기

노션에서 쓰던 페이지는 노션의 내보내기 파일로 옮겨 올 수 있습니다.

1. 노션에서 설정 › 내보내기(페이지 하나라면 페이지의 ⋯ › 내보내기)를 열고 Markdown & CSV를 고릅니다. 하위 페이지 포함과 하위 페이지용 폴더 만들기를 켜 주세요.
2. Inkling의 워크스페이스 메뉴에서 'Notion에서 가져오기 (.zip)'를 누르고 '.zip 선택'으로 받은 파일을 그대로 올리시면 됩니다.

페이지는 문서로, CSV 데이터베이스는 데이터베이스로 들어오고, 이미지와 파일은 첨부로 올라갑니다. 수식은 수식으로 옮겨지지만 콜아웃은 아직 인용으로 바뀝니다. 다 끝나면 몇 개를 가져왔고 어떤 링크를 찾지 못했는지 보고서로 보여 줍니다.

노션이 아닌 마크다운 파일은 같은 메뉴의 '가져오기 (.md/.zip)'로, `.md` 파일이 든 폴더는 '폴더 가져오기'로 올리시면 됩니다.

## 내보내기

페이지 하나는 ⋯ 메뉴에서 '내보내기 (.md)'로, 하위 페이지까지 함께 받으시려면 '하위 포함 내보내기 (.zip)'로 받습니다. 캔버스는 `.canvas` 파일로 나옵니다. PDF가 필요하시면 페이지 머리글 ⋯ 메뉴의 'PDF로 내보내기'를 누르시면 됩니다. 데이터베이스는 '현재 뷰를 CSV로 내보내기'와 '현재 뷰를 Excel로 내보내기'를 씁니다.

워크스페이스 전체는 워크스페이스 메뉴의 '전체 내보내기 (.zip)'로 받을 수 있는데, 소유자가 이 권한을 일부에게만 열어 두었을 수도 있습니다. ⋯ 메뉴의 '노션으로 보내기'는 서버에 노션 연동이 설정된 경우에만 동작합니다.

## 휴지통과 버전 히스토리

페이지를 지우면 사이드바 아래쪽의 휴지통으로 갑니다. 휴지통을 열어 '복원'하거나 '영구 삭제'할 수 있습니다. 휴지통은 기본으로 30일 동안 보관하는데, 소유자가 워크스페이스 설정 › 일반 › 휴지통 보관 기간에서 바꿨을 수도 있습니다. 지울 때마다 묻는 게 번거로우시면 설정 › 휴지통 › 삭제 전 확인을 끄시면 됩니다. 그러면 확인 없이 휴지통으로 보내고 대신 되돌리기 알림을 띄웁니다.

글을 예전 상태로 돌리고 싶을 때는 오른쪽 패널의 버전 히스토리를 봅니다. '전체 보기'를 누르면 같은 이름의 창이 열리고, 여기서 버전을 미리 보거나 '현재와 비교'로 바뀐 곳을 확인할 수 있습니다. 중요한 시점에는 '지금 스냅샷'으로 직접 저장해 두셔도 되고, '이 버전으로 복원'을 누르면 복원하기 전의 상태도 먼저 저장해 둡니다.

워크스페이스를 통째로 지운 경우에는 소유자가 30일 안에 설정 › 삭제한 워크스페이스에서 되살릴 수 있습니다.

## 설정과 사이드바

설정은 ⌘,를 누르거나 사이드바 아래쪽의 '설정'으로 엽니다.

설정 화면의 항목은 저장되는 곳이 두 가지로 나뉩니다. 계정, 알림, 캘린더 구독 (iCal), 사이드바, 그리고 모양 묶음 안에 있는 언어는 계정에 저장되기 때문에 어느 기기에서 열어도 같습니다. 반면 편집기(본문 폭, 맞춤법 검사, 단어 수 표시), 파일 · 링크(앱 시작 시 열 페이지, 새 페이지 위치, 링크 미리보기), 휴지통(삭제 전 확인), 모양(배율, 테마)은 지금 쓰는 기기의 브라우저에만 저장됩니다. 맥과 태블릿에서 글씨 크기를 다르게 두고 싶은 경우가 많아서 이렇게 나눴습니다.

### 사이드바 메뉴

사이드바 위쪽에 나오는 검색, 그래프, 태그, 웹 공유, 마감, 캘린더, 활동, 오늘 메뉴는 설정 › 사이드바에서 숨기거나 순서를 바꿀 수 있습니다. 끌어서 옮기셔도 되고 ↑/↓ 버튼을 쓰셔도 됩니다. 처음 상태로 돌리려면 '기본값으로 되돌리기'를 누르시면 됩니다. 사이드바에서 메뉴를 우클릭(휴대폰에서는 길게 누르기)하고 '사이드바에서 숨기기'를 골라도 같습니다. 숨긴 메뉴도 ⌘P 팔레트나 단축키로는 그대로 열립니다.

사이드바 전체를 접고 펴는 단축키는 ⌘\입니다.

## 단축키

글을 입력하는 중이 아닐 때 `?`를 누르면 앱 안에서 단축키 목록을 볼 수 있습니다. 설정 › 단축키에도 같은 목록이 있습니다. 단축키를 바꾸는 기능은 아직 없습니다.

## 휴대폰과 태블릿

따로 설치할 앱은 없고 브라우저에서 바로 쓰시면 됩니다. 앱처럼 쓰고 싶으시면 브라우저로 서버 주소를 연 다음 브라우저 메뉴의 설치 또는 홈 화면에 추가를 고르시면 됩니다(PWA). 이렇게 설치하면 주소창 없이 따로 열립니다.

페이지 머리글에는 즐겨찾기, 웹에 공유, 접속 중인 사람, 오른쪽 패널, ⋯만 있고 필기 모드, 편집 잠금, 페이지 알림, PDF, 테마는 ⋯ 메뉴 안에 있습니다(⋯에 점이 보이면 잠금이 걸렸거나 팔로우 중인 페이지입니다). 화면이 좁을 때는 웹에 공유와 오른쪽 패널도 ⋯ 안으로 들어갑니다.

## 자주 묻는 질문

### 내 페이지는 누가 볼 수 있나요?

공유 구역의 페이지는 워크스페이스 멤버 모두가 봅니다. 개인 구역의 페이지는 본인과, 본인이 연결한 AI 앱만 볼 수 있습니다.

### 읽기만 하는 멤버를 둘 수 있나요?

아직 읽기 전용 역할은 없습니다. [편집 잠금](#편집-잠금)을 걸어 정해진 사람만 고치게 하시거나, 읽기만 하면 되는 분께는 [웹 공유 링크](#웹에-공유)를 보내시는 방법이 있습니다.

### 페이지를 실수로 지웠어요.

사이드바 아래쪽의 휴지통을 열고 '복원'을 누르시면 됩니다. 페이지는 그대로 있는데 내용을 예전으로 돌리고 싶으신 거라면 오른쪽 패널의 버전 히스토리를 쓰시면 됩니다.

### 누가 내 페이지를 고쳤는지 알고 싶어요.

오른쪽 패널의 버전 히스토리나 활동 화면에서 누가 무엇을 바꿨는지 볼 수 있습니다. AI가 고친 경우에는 '경유'가 붙어 있어서 구분됩니다.

### AI 앱이 페이지가 잠겨 있다고 해요.

편집 잠금이 에이전트의 편집을 막고 있는 상태입니다. 페이지 담당자나 워크스페이스 관리자에게 잠금 설정을 바꿔 달라고 요청하셔야 합니다.

### 알림 메일이 오지 않아요.

설정 › 알림을 먼저 확인해 보시기 바랍니다. 서버에 메일 설정이 없다는 안내가 나온다면, 그 서버에서는 알림을 앱 안에서만 볼 수 있습니다.

### 워크스페이스에서 나가고 싶어요.

워크스페이스 설정 › 위험 구역에서 '워크스페이스 나가기'를 누르시면 됩니다. 그 워크스페이스에 있던 개인 페이지는 휴지통으로 갑니다. 본인이 유일한 소유자라면 다른 멤버에게 소유권을 먼저 넘기셔야 나갈 수 있습니다.
